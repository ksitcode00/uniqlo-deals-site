# UNIQLO Deals Explorer

Public website: https://ksitcode00.github.io/uniqlo-deals-site/

This repository contains generated website assets and publicly sourced product snapshots. The original application source and collection pipeline remain in a private repository. Data is checked approximately every six hours. Available regional sources and limitations are shown in the application.

Prices, stock and membership conditions must be confirmed with official stores. This independent personal project is not affiliated with UNIQLO. Mainland China data and interface inspiration: https://goodprices.online/uniqlo/ .
